# Submission Checklist (Anna University M.E. report)

Tick each box before printing. Rules are from `docs/anna-university/format-guide.md`.

## Content
- [ ] Title is the same on cover page, certificate, abstract and synopsis
- [ ] Cover and title page filled in (name, register number, programme, month and year)
- [ ] Bonafide certificate has supervisor and HOD names and designations; signatures obtained
- [ ] Abstract in English and in Tamil; Tamil text checked by a Tamil speaker
- [ ] Acknowledgement on one page, signed
- [ ] Table of contents, list of tables and list of figures have correct page numbers (update fields in Word)
- [ ] List of abbreviations included
- [ ] Every chapter has the required headings; conclusions and (Phase I) work schedule for Phase II present
- [ ] Every reference in the list is cited in the text, and every in-text citation is in the list
- [ ] Every reference opened and checked against the source; the [VERIFY] flags removed
- [ ] Results chapters contain only numbers that were actually measured
- [ ] Appendix with List of Publications (if any)

## Layout
- [ ] A4; margins top 30-35, bottom 25-30, left 35-40, right 20-25 mm
- [ ] Times New Roman; 13 pt (or the size your department confirmed); 1.5 spacing
- [ ] Single spacing only for long tables, quotations, footnotes, captions, references
- [ ] Double spacing for certificate, acknowledgement, abstract
- [ ] Chapter heading 50 mm from the top; titles in capitals, centred
- [ ] Paragraph first lines indented 20 mm
- [ ] Page numbers top right: Roman for front matter, Arabic from Chapter 1
- [ ] Table captions above and left; figure captions below and centred; numbered by chapter (Table 3.1, Figure 3.4)
- [ ] Tables and figures inside the margins
- [ ] No sub-heading stranded at the bottom of a page
- [ ] Length meets the minimum (Phase I: 25 pages; Phase II: 40 pages)

## Before binding
- [ ] Plagiarism check done and within your college's limit
- [ ] Spelling and grammar pass
- [ ] Printed on 80 gsm or heavier white paper, black ink
- [ ] Required number of copies printed; CD prepared if needed
- [ ] Cover colour and binding style as your department requires
