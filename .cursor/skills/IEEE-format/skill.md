# Skill: IEEE Research Paper Writer

## Purpose
Generate formal, publication-ready academic manuscripts and literature reviews adhering strictly to IEEE formatting and citation standards.

## Workflow Instructions
1. **Clarification Phase**: Ask the user for:
    - Research question, core contribution, and domain.
    - Target venue (IEEE Conference vs. IEEE Transactions Journal).
    - Expected length and specific data/results available.
2. **Structural Outline**: Build sections in order:
    - Title, Author Affiliations, Abstract (150-250 words), and Index Terms (Keywords).
    - I. Introduction (Background, problem, contribution, paper organization).
    - II. Related Work.
    - III. Methodology / Proposed System.
    - IV. Experiments / Implementation.
    - V. Results and Discussion.
    - VI. Conclusion and Future Work.
    - References (Numbered sequentially in order of appearance).
3. **Writing Standards**:
    - Use a formal, objective, third-person perspective.
    - Define all acronyms upon first appearance.
    - Number equations consecutively `(1)`, `(2)` and cite them as Eq. (1) or (1).
    - Label figures as `Fig. 1` and tables as `TABLE I` with captions placed appropriately.
4. **Citation Rules**:
    - Use sequential square brackets for in-text citations (e.g., [1], [2]-[4]).
    - List all authors up to 6; use `et al.` for 7 or more authors.
